# Common Lisp for Zed

Syntax highlighting for [Common Lisp](https://lisp-lang.org/). Nothing else.

## Installing

This extension is not in the Zed registry, so you have to install it as a dev extension. Start by cloning the repo wherever you want:

```
git clone https://github.com/bi3mer/zed-cl-syntax-highlighting.git
```

Then, open the command palette (`ctrl-shift-p` or `cmd-shift-p` depending on OS) and run `zed: install dev extension`. Select the directory you just cloned and this extension will install. Note, Zed needs network access to install.

At this point, you should have syntax highlighting for the following file extensions:

- `.lisp`
- `.lsp`
- `.cl`
- `.asd`

## Updating

On the off-chance this repo is updated and you want to update, first go to the repo you cloned above and run `git pull`. Then, in Zed, run `zed: rebuild dev extension`.

## Problems

If a Common Lisp file opens without highlighting, read `zed: open log` and please [open an issue](https://github.com/bi3mer/zed-cl-syntax-highlighting/issues) with the output so I can fix it.
